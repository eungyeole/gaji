Build the current app

Run Rift on a Mac.

Requires macOS 26, Xcode 26 with Swift 6.2, stable Rust, and Git.

$ git clone https://github.com/eungyeole/rift.git
$ cd rift
$ cargo build -p rift-ffi --release
$ swift run --package-path apps/macos RiftMac
